# Herramientas web

[Volver al catálogo](../README.md)

## DNS, correo y sitios web

| Herramienta | Para qué sirve |
| --- | --- |
| [DNSChecker](https://dnschecker.org/) | Comparar las respuestas de distintos resolvedores públicos para un registro DNS. |
| [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/) | Consultar registros DNS desde el navegador. |
| [MXToolbox SuperTool](https://mxtoolbox.com/SuperTool.aspx) | Revisar registros MX y consultar listas de bloqueo al diagnosticar problemas de correo. |
| [Qualys SSL Labs](https://www.ssllabs.com/ssltest/) | Revisar el certificado, la cadena de confianza y la configuración TLS de un sitio público. |
| [SecurityHeaders](https://securityheaders.com/) | Revisar las cabeceras de seguridad HTTP que entrega un sitio. |
| [Internet.nl](https://internet.nl/) | Comprobar estándares de seguridad en sitios web y servicios de correo. [Código fuente](https://github.com/internetstandards/Internet.nl). |

## Archivos sospechosos, filtraciones y reputación

| Herramienta | Para qué sirve |
| --- | --- |
| [VirusTotal](https://www.virustotal.com/) | Buscar informes existentes sobre archivos por hash y consultar la reputación de dominios o URL. |
| [Have I Been Pwned](https://haveibeenpwned.com/) | Comprobar si una dirección de correo aparece en filtraciones conocidas. |
| [urlscan.io](https://urlscan.io/) | Buscar análisis existentes de páginas y revisar redirecciones y capturas. |
| [URLhaus](https://urlhaus.abuse.ch/browse/) | Consultar URL asociadas a la distribución de malware. |
| [AbuseIPDB](https://www.abuseipdb.com/) | Consultar reportes de abuso asociados a una dirección IP. |
| [CyberChef](https://gchq.github.io/CyberChef/) | Decodificar datos y calcular hashes en el navegador. [Código fuente](https://github.com/gchq/CyberChef). |

## Recuperación de archivos

| Herramienta | Para qué sirve |
| --- | --- |
| [No More Ransom](https://www.nomoreransom.org/en/decryption-tools.html) | Buscar un descifrador para una familia de ransomware. Los descifradores se ejecutan localmente. |

Para revisar un archivo interno, busca primero su hash. Antes de enviar archivos o URL a un servicio externo, revisa la visibilidad de los resultados y si los datos incluyen información confidencial.
