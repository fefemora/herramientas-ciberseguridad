## DNS, correo y sitios web

| Herramienta | Para qué sirve |
| --- | --- |
| [DNSChecker](https://dnschecker.org/) | Permite comparar las respuestas de distintos resolvedores públicos para un registro DNS. |
| [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/) | Sirve para consultar registros DNS desde el navegador. |
| [MXToolbox SuperTool](https://mxtoolbox.com/SuperTool.aspx) | Ayuda a diagnosticar problemas de correo al revisar registros MX y listas de bloqueo. |
| [Qualys SSL Labs](https://www.ssllabs.com/ssltest/) | Evalúa el certificado, la cadena de confianza y la configuración TLS de un sitio público. |
| [SecurityHeaders](https://securityheaders.com/) | Muestra las cabeceras de seguridad HTTP que entrega un sitio. |
| [Internet.nl](https://internet.nl/) | Comprueba si un sitio web o un servicio de correo admite estándares de seguridad. [Código fuente](https://github.com/internetstandards/Internet.nl). |

## Archivos sospechosos, filtraciones y reputación

| Herramienta | Para qué sirve |
| --- | --- |
| [VirusTotal](https://www.virustotal.com/) | Permite buscar informes de archivos por hash y consultar la reputación de dominios o URL. |
| [Have I Been Pwned](https://haveibeenpwned.com/) | Indica si una dirección de correo aparece en filtraciones conocidas. |
| [urlscan.io](https://urlscan.io/) | Sirve para buscar análisis previos de páginas y revisar sus redirecciones y capturas. |
| [URLhaus](https://urlhaus.abuse.ch/browse/) | Permite consultar si una URL está asociada a la distribución de malware. |
| [AbuseIPDB](https://www.abuseipdb.com/) | Muestra los reportes de abuso asociados a una dirección IP. |
| [CyberChef](https://gchq.github.io/CyberChef/) | Decodifica datos y calcula hashes directamente en el navegador. [Código fuente](https://github.com/gchq/CyberChef). |

## Recuperación de archivos

| Herramienta | Para qué sirve |
| --- | --- |
| [No More Ransom](https://www.nomoreransom.org/en/decryption-tools.html) | Ayuda a encontrar un descifrador para una familia de ransomware. Los descifradores se ejecutan localmente. |

Para revisar un archivo interno, busca primero su hash. Antes de enviar archivos o URL a un servicio externo, revisa la visibilidad de los resultados y si los datos incluyen información confidencial.
