| --- | --- |
| <img src="https://www.google.com/s2/favicons?domain=dnschecker.org&amp;sz=32" width="16" height="16" alt=""> [DNSChecker](https://dnschecker.org/) | Permite comparar las respuestas de distintos resolvedores públicos para un registro DNS. [Ver guía](dnschecker/README.md) |

| <img src="https://www.google.com/s2/favicons?domain=mxtoolbox.com&amp;sz=32" width="16" height="16" alt=""> [MXToolbox SuperTool](https://mxtoolbox.com/SuperTool.aspx) | Ayuda a diagnosticar problemas de correo al revisar registros MX y listas de bloqueo. |

| <img src="https://www.google.com/s2/favicons?domain=virustotal.com&amp;sz=32" width="16" height="16" alt=""> [VirusTotal](https://www.virustotal.com/) | Permite buscar informes de archivos por hash y consultar la reputación de dominios o URL. [Ver guía](virustotal/README.md) |

## Recuperación de archivos

| Herramienta | Para qué sirve |
| --- | --- |
| <img src="https://www.google.com/s2/favicons?domain=nomoreransom.org&amp;sz=32" width="16" height="16" alt=""> [No More Ransom](https://www.nomoreransom.org/en/decryption-tools.html) | Ayuda a encontrar un descifrador para una familia de ransomware. Los descifradores se ejecutan localmente. |

Para revisar un archivo interno, busca primero su hash. Antes de enviar archivos o URL a un servicio externo, revisa la visibilidad de los resultados y si los datos incluyen información confidencial.
