## ¿Qué necesitas resolver?

- [Revisar si un cambio de DNS ya se refleja](web/dnschecker/README.md#comprobar-un-cambio-de-registro-a) con DNSChecker.
- [Revisar un archivo sospechoso por SHA-256](web/virustotal/README.md#revisar-un-archivo-sospechoso-por-sha-256) con VirusTotal.
- [Revisar si un correo aparece en una filtración](web/have-i-been-pwned/README.md#revisar-si-un-correo-aparece-en-una-filtración) con Have I Been Pwned.
- [Diagnosticar una advertencia de certificado HTTPS](web/qualys-ssl-labs/README.md#diagnosticar-una-advertencia-de-certificado-https) con Qualys SSL Labs.
- [Revisar los registros MX después de una migración de correo](web/google-admin-toolbox-dig/README.md#revisar-los-registros-mx-después-de-una-migración-de-correo) con Google Admin Toolbox Dig.
- [Decodificar un campo Base64 de un registro](web/cyberchef/README.md#decodificar-un-campo-base64-de-un-registro) con CyberChef.
- [Comprobar cabeceras HTTP después de un cambio](web/securityheaders/README.md#comprobar-cabeceras-http-después-de-un-cambio) con SecurityHeaders.
- [Buscar un descifrador para archivos afectados por ransomware](web/no-more-ransom/README.md#buscar-un-descifrador-para-archivos-afectados-por-ransomware) con No More Ransom.
- [Investigar un rechazo de correo por reputación de IP](web/mxtoolbox/README.md#investigar-un-rechazo-de-correo-por-reputación-de-ip) con MXToolbox SuperTool.
- [Verificar la seguridad del correo de un dominio](web/internet-nl/README.md#verificar-la-seguridad-del-correo-de-un-dominio) con Internet.nl.
